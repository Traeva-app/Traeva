## Boundaries (what has not been proven)
- These export cases have **no dynamic verification**: an uncertain result after the commit (`result_unconfirmed`; only the page text was checked statically, see [#104 R2](https://github.com/P30g53/Traeva/issues/26#issuecomment-6102455752)), a full disk or a real I/O failure, and recovery after the process exits during an export. The export unit tests do not cover these cases either.
- The Finder open item uses the TXT evidence from `069208a` (the student agreed to carry it over). MD's default app (Xcode) was identified, but when MD was tried again on `c6a711d`, the window for the original document still could not be located on its own, so it does not count as PASS.
- Word (#66) preview and entry point are handled separately. Opening historical Word versions in Word is still No-Go.
- The final integration acceptance of #26 / #37 is done separately.
