Chrome download sources

Keep download sources in your local Traeva library. Review suggested file matches in Traeva when it suits you. Downloads never open a confirmation popup.

Connect for the first time
  1. Open Traeva. In Settings, authorize the folder where Chrome saves your downloads.
  2. In Source Memory, enable Chrome collection and open Connect Chrome extension.
  3. Copy that app's address and pairing token below. Select Collect new downloads and save settings.
  4. Check the connection. Download a small TXT file into a listed folder, then find it in Source Memory. A saved record and a confirmed file association are separate steps.
Pair this Chrome profile
